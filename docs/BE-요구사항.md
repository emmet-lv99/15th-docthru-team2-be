# 📚 독스루 (DocsThrough) - 백엔드 요구사항

> ⭐ **이 문서는 1순위 기준입니다** — 제품을 "무엇을" 만드는지 여기에서 정합니다.
> 구현 방법(API 형태, 필드명)은 [`API-명세.md`](./API-명세.md) 이 이어받아요.
> 읽는 순서는 루트 README 의 '문서 보는 순서' 절을 참고해 주세요.

## 1. 개요

- **프로젝트명:** 독스루 (개발 문서 번역 챌린지 서비스)
- **난이도:** 중급
- **소개:**  
  대다수의 개발 시장 콘텐츠가 영어로 작성되어 있어, 영어를 잘하지 못하는 한국인들이 해당 기술을 습득하는데 어려움을 겪고 있습니다.  
  따라서 개발 관련 영어 문서를 함께 번역하는 챌린지를 진행하고, 번역 작업 에디터에서 번역을 진행하며 번역문에 대한 피드백을 주고받을 수 있는 서비스를 제작합니다.

---

## 2. 기능 요구사항

### 🔐 2.2. 유저 인증 & 등급 시스템

- [ ] **회원가입:** 유저 회원가입 기능을 제공합니다.
- [ ] **로그인:** 계정으로 로그인하면 부여된 권한(어드민 / 일반 유저)에 맞는 기능에 접근할 수 있습니다.
- [ ] **유저 등급 (일반 / 전문가):** 유저 활동에 따라 등급이 부여됩니다.
  - `일반 등급`: 기본 등급
  - `전문가 등급`: 다음 조건 중 하나 이상 충족 시 부여
    1. 챌린지 참여 횟수 5회 이상 **AND** 추천 선정 횟수 5회 이상
    2. 챌린지 참여 횟수 10회 이상
    3. 추천 선정 횟수 10회 이상
- [ ] **로그아웃:** 로그아웃 기능을 제공합니다.

### 📖 2.3. 번역 챌린지 조회

- [ ] **번역 챌린지 목록 조회**
  - 제목, 분야(Next.js, Modern JS, Web 등), 문서타입(공식문서, 블로그, 도서, 기타 등), 마감일, 상태(진행 중, 마감), 참여 인원, 최대 참여 가능 인원 표시
  - 제목 검색, 필터링(분야, 문서타입, 상태 등), 페이지네이션 포함
- [ ] **번역 챌린지 상세 정보 조회**
  - 챌린지 정보 및 상세 내용 조회
  - **원문 보기:** 클릭 시 새 창으로 번역문 원본 페이지 이동
  - **마감 전 챌린지:** '챌린지 도전하기' 가능
  - **마감된 챌린지:** 가장 많은 추천을 받은 작업물 조회
- [ ] **번역 챌린지 참여 현황 조회**
  - 순위, 참여 유저 닉네임, 하트 수, 최종 제출 시간 등 정보 제공 (페이지네이션 포함)
  - 클릭 시 작업물 상세 조회 페이지로 이동

### ✍️ 2.4. 번역 챌린지 참여

- [ ] **참여 기준:** '도전하기' 버튼을 누른 즉시 참석자로 카운트됩니다.
- [ ] **도전 조건:** 일반 유저, 마감일 미도달, 현재 참여 인원 < 최대 인원일 때 가능
- [ ] **에디터 & 임시 저장**
  - 번역 에디터 제공 및 임시 저장 기능 지원
  - 임베드된 원문을 확인하며 번역 작성 가능
  - **임시 저장 불러오기:** `LocalStorage`에 저장된 데이터가 있을 경우 에디터 첫 진입 시 모달 표시
    - 🎯 **실제 구현은 서버 저장** — 저장 위치만 서버 `drafts` 로 바뀌고 **모달 동작은 동일**해요. 현재 계약은 [`API-명세.md`](./API-명세.md) 의 `drafts` 를 봐 주세요.
  - 모달에서 목록(제목/제목 없음) 선택 시 에디터에 자동 채움
- [ ] **제출 및 포기**
  - 마감일 전 번역 제출 가능
  - 도전했던 챌린지 포기하기 기능 제공

### ➕ 2.5. 번역 챌린지 신청 관리

- [ ] **신규 챌린지 신청 (일반 유저):** 원하는 문서의 챌린지 정보, 희망 마감일, 최대 인원 설정하여 신청 (HTML 기본 인풋 또는 외부 라이브러리 활용)
- [ ] **신청 목록 조회 (어드민):** 테이블 형태로 조회 (검색, 필터링, 페이지네이션 포함)
- [ ] **승인 및 거절 (어드민):** 원문 및 신청 내용 확인 후 승인/거절 처리 (승인 시 챌린지 목록에 노출)

### 🛠️ 2.6. 챌린지 및 콘텐츠 관리

- [ ] **챌린지 수정/삭제:** 어드민 전용 기능 (일반 유저 불가)
- [ ] **작업물 수정/삭제:** 어드민 및 작성자 본인 가능 (완료된 챌린지의 작업물은 수정/삭제 불가)
- [ ] **피드백 수정/삭제:** 어드민 및 작성자 본인 가능 (완료된 챌린지의 피드백은 수정/삭제 불가)

### 💬 2.7. 작업물 관리 및 피드백

- [ ] **번역 작업물 상세 조회:** 각 작업물에 대한 피드백 조회 및 피드백 작성
- [ ] **피드백 목록:** N개 표시 후 '더 보기' 버튼을 통한 추가 확인 (페이지네이션)
- [ ] **하트(좋아요):** 각 작업물에 하트 남기기 기능

### 📁 2.8. 나의 챌린지 관리

- [ ] **참여 중인 챌린지 목록:** 진행 중인 챌린지 조회, '계속 도전하기' 버튼으로 작성물 수정 가능 (검색, 필터링, 무한스크롤)
- [ ] **완료한 챌린지 목록:** 마감된 챌린지 및 내가 제출한 번역문 조회
- [ ] **내가 신청한 챌린지 목록:** 어드민에 신청한 챌린지 목록 및 상태(승인 대기, 승인, 거절) 조회
  - `승인 대기`: 신청 취소 가능 (취소 시 어드민 목록에서 제외)
  - `신청 거절 / 삭제`: 사유 조회 가능
  - `승인됨`: 해당 챌린지 상세 페이지로 이동

## 3. 심화 요구사항

### 🔑 3.1. OAuth 인증

> ℹ️ **BE 계약에는 포함** — 심화 요구사항(3.1)이고, BE 2경로(`GET /auth/google` · `GET /auth/google/callback`)가
> 구현돼 계약에 들어갔어요(42→44건). 구글 자격 증명(GOOGLE_CLIENT_ID·SECRET)이 아직 없어서,
> 증명 없이는 시작 라우트가 400으로 응답하고 **FE 버튼 추가**가 남은 일이에요.

- [ ] 구글 아이디(Google OAuth) 회원가입 및 로그인 지원

### 🔔 3.2. 알림 안내 (Notification)

> _새로고침 시 데이터를 fetch하여 사용자에게 노티피케이션을 주는 방식으로 구현_

- [ ] **변경사항 알림:** 도전 작업물, 챌린지 이름, 피드백이 수정/삭제되었을 때 전송 (수정/삭제 날짜 포함)
- [ ] **챌린지 상태 알림:** 신청한 챌린지가 승인, 거절, 삭제되었을 때 전송 (상태 변경 날짜 포함)
- [ ] **새로운 작업물 알림:** 신청한 챌린지에 새 작업물이 추가되었을 때 전송 (추가 날짜 포함)
- [ ] **새로운 피드백 알림:** 내 작업물에 새 피드백이 등록되었을 때 전송 (추가 날짜 포함)
- [ ] **마감 알림:** 신청한 챌린지가 마감되었을 때 전송 (마감 날짜 포함)
- [ ] **어드민 처리 알림:**
  - 챌린지 수정/삭제 시 어드민이 작성한 사유와 함께 알림 전송
  - 피드백 수정/삭제 시 작성자에게 알림 전송
- [ ] **알림 읽음 처리:** 사용자가 확인 시 읽음 처리 기능

### 🏗️ 3.4. 코드 레벨 아키텍처 적용

- [ ] Layered Architecture 적용
- [ ] 역할 분리: `Router` ➔ `Controller` ➔ `Service` ➔ `Repository`
